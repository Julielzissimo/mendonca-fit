# Instruções do projeto

- Sempre que uma alteração for aplicada e validada, publique-a no GitHub Pages para que a versão atualizada possa ser testada.
- A publicação acontece ao enviar o commit para a branch `main`, conforme `.github/workflows/deploy-pages.yml`.
- Após o envio, acompanhe o workflow até confirmar que o deploy foi concluído ou informar qualquer falha.
